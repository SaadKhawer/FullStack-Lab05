# CS-301L: Full Stack Web Development - Lab 05

This repository contains the completed tasks for **Lab 05 — ES6 Features, Modules, Callbacks, Promises, and Async/Await** for the CS-301L course.

## Overview of Tasks

This project includes the implementation of four distinct tasks designed to practice modern JavaScript (ES6+) features:

- **Task 1: University Course Enrollment Manager** 
  Demonstrates the use of the Spread Operator and Rest Parameters to merge arrays, copy data, and process student enrollment information.
  
- **Task 2: Student Utility Module** 
  Implements JavaScript ES6 Modules. Contains reusable helper functions (named and default exports) to calculate totals, averages, grades, and pass/fail statuses, which are imported into the main script.

- **Task 3: Online Examination Workflow**
  Simulates an asynchronous examination process using nested callbacks (Callback Hell) and `setTimeout()`. Includes an error-first callback mechanism for student verification.

- **Task 4: University Result Portal**
  Showcases the use of Promises and `async/await` syntax to simulate fetching data from a database. Features include searching for an individual student's result and using `Promise.all()` to load all student results concurrently.

## Technologies Used
- HTML5
- CSS3 (Custom Bootstrap-style cards)
- JavaScript (ES6 Modules, Promises, Async/Await)

## How to Run

Since this project uses ES6 Modules (`type="module"`), it cannot be run directly by double-clicking the `index.html` file (due to CORS policies).

1. Open this folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by Ritwick Dey) if you haven't already.
3. Right-click on `index.html` and select **"Open with Live Server"**.
4. The project will open in your default browser at `http://127.0.0.1:5500/index.html`.
